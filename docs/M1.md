# M1 截图一键记账：使用说明

付完款停在支付成功页（或订单详情页），**长按两个音量键**，几秒后弹出通知“已记账 ¥26.00 · 微信 · 商户 · 餐饮”。记错了点通知上的“撤销”。

M0′ 探针的实测结论（2026-11-26）决定了这个版本的做法：

- 触发用无障碍快捷方式“长按音量键”，平时无感，不用悬浮按钮。
- 微信页面读不到无障碍文字，但截图正常，所以识别以**截图 + 看图模型**为主，读到的屏幕文字只用来核对金额。
- 等模型返回的几秒里 App 可能被 vivo 冻住，所以识别期间开一个短时前台服务（通知栏会短暂出现“正在识别…”），识别完立即退出；失败的自动重试最多 3 次。
- 服务被系统杀掉后，第一次长按会把它唤醒。如果这时前台是微信、支付宝、美团等付款 App，会**直接识别**，不用再按第二次（设置页可关闭）。

## 1. 安装

在仓库 **Actions → Build APK → 最新一次运行 → Artifacts** 下载 `bookkeeper-debug-apk`，解压安装。
没有配置固定签名的话（见 `docs/M0.md`），需要先卸载旧版。探针的样本不会迁移到账本里。

## 2. 一次性设置

1. **允许受限制的设置**：设置 → 应用 → 截图记账 → 右上角 ⋮ → 允许受限制的设置。
2. **开启无障碍服务**：设置 → 无障碍 → 截图记账 → 打开。
3. **快捷方式**：同一页面 → 快捷方式，勾选“长按音量键”（悬浮按钮可以不勾）。
4. **通知权限**：允许。
5. **DeepSeek API Key**：App 的“设置”页填写，模型默认 `deepseek-flash`。

## 3. 日常用法

| 场景 | 做法 |
| --- | --- |
| 付款后 | 停在成功页，长按两个音量键 |
| 订单详情里有商品 | 再在订单详情页长按一次：同金额、15 分钟内的会合并成一笔，补上商品明细 |
| 账单列表、月付账单、中行明细 | 截长图，分享到“截图记账”，或在账本页“导入截图”；每行一笔，和已有的自动去重 |
| 记错了 | 通知上点“撤销”，或在账本里打开这笔修改 / 删除 |
| 识别失败或没识别到 | “识别记录”页能看到截图、模型原始输出，可以重新识别 |

去重规则：金额相同、类型相同、时间相差 15 分钟内（屏幕上没有交易时间时按截图时间，放宽到 30 分钟）的算同一笔，后来的只补充空缺字段和商品明细。

## 4. 导出

设置页：

- **导出 CSV**：账本，一行一笔，用 Excel 打开。
- **导出 JSON**：账本 + 商品 + 全部识别记录（含模型原始输出，不含图片），出问题时发给我排查。

文件在 `下载/Bookkeeper/`。

## 5. 隐私

- 只在你长按音量键、点磁贴或分享截图时截屏一次；服务不订阅屏幕事件，不在后台常驻。
- 截图整张发给 DeepSeek 识别；屏幕文字发送前会把手机号和 15 位以上的长数字打码。
- 账本和截图存在 App 私有目录，卸载即删除。API Key 存在 App 私有存储，之后改为 Keystore 加密。
