# M0′ 读屏探针：使用说明

M0 的通知采样证明了“常驻后台 + 抓通知”在这台 vivo 上靠不住，所以改为付款后**主动触发**识别。
这个探针只采样、不记账，用 2 到 3 天在真实页面上回答四个问题：

1. OriginOS 上无障碍悬浮按钮好不好用，磁贴是否可以作为备用入口。
2. 哪些付款 / 账单页面截图会黑屏（`FLAG_SECURE`），哪些页面节点文字为空。
3. “节点文字 → 文本模型”和“截图 → 看图模型”两条路径，金额准确率和耗时各是多少。
4. 无障碍服务一周内会不会被系统杀掉、被杀几次。

## 1. 安装

在仓库 **Actions → Build APK → 最新一次运行 → Artifacts** 下载 `bookkeeper-probe-debug-apk`，解压安装。
包名和 M0 相同；如果没有配置固定签名（见 `docs/M0.md`），需要先卸载 M0 再装。M0 的样本你已经导出过了。

## 2. 一次性设置

1. **允许受限制的设置**：Android 13 起，侧载 App 的无障碍开关默认是灰的。先到 设置 → 应用 → 读屏记账 M0′ → 右上角 ⋮ → 允许受限制的设置。
2. **开启无障碍服务**：设置 → 无障碍 → 读屏记账 → 打开。
3. **无障碍按钮**：同一页面里的“快捷方式”选“无障碍按钮”（悬浮在屏幕边上）。vivo 上的入口名称可能不同，找不到也没关系，用磁贴。
4. **磁贴**：App 概览页点“添加”，或下拉通知栏 → 编辑，把“读屏记账”拖进去。
5. **通知权限**：允许，用来显示每次的识别结果。
6. **DeepSeek API Key**：App 的“设置”页填写。默认两条路径都用 `deepseek-flash`。

## 3. 怎么采

- **付款后**：停在支付成功页或订单详情页，点一下无障碍按钮（或下拉点磁贴）。会先弹一个“已采样 · 文字 N 字 · 截图正常/黑屏”的提示，几秒后弹识别结果通知。
- **账单列表**：在账单页用系统滚动截屏截一张长图，分享到“读屏记账”；也可以直接在账单页点按钮读屏。
- **标注**：在“样本”页点开一条，选页面类型、填实际金额、标“文字路径 / 看图路径 对不对”。标注越全，结论越可靠。

每类页面采 3 次以上：微信支付成功 / 账单、支付宝支付成功 / 账单、美团订单 / 月付账单、抖音订单 / 月付账单、京东 / 小红书订单、中行交易明细。

## 4. 导出

概览页：

- **导出 JSON**：节点文字、两路识别结果、耗时、标注、服务连接记录，不含图片。
- **导出 ZIP**：同一个 JSON 加上全部截图，方便核对看图路径。截图里可能有余额、卡号尾号等信息，分享前注意。

文件在 `下载/Bookkeeper/`。把文件发回线程即可。

## 5. 采了什么、发了什么

- 读屏只在你点按钮或磁贴的那一刻发生；服务不订阅屏幕变化事件，不在后台运行，也没有常驻通知。
- 节点文字发给模型前，会把手机号和 15 位以上的长数字打码。截图整张上传，探针阶段不裁剪。
- 所有数据存在 App 私有目录，卸载即删除。API Key 存在 App 私有存储，正式版改为 Keystore 加密。
